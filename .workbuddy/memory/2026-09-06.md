## 给 Stellar 博客加渐变背景

操作：在用户的 `_config.stellar.yml` 写 `style.leftbar.*`（侧边栏水晶紫半透明）和 `inject.head` 一段 `<style>`（给 `body > .sitebg` 加甜豆清新渐变 + dark 模式下的同色系深色版）。

**关键发现**：主题的 `style.site.background-image` 不能直接写 `linear-gradient(...)` —— 主题的 Stylus `convert()` 会把含逗号的字符串截断到第一个逗号（输出 `background-image: linear-gradient(135deg,;`）。CSS 端完全干净，但视觉上等同于没设。

**解决办法**：把所有渐变相关 CSS 写到 `theme.inject.head` 的 `<style>` 块里，绕过 stylus convert，让浏览器自己解析。同时顺手把 `.siteblur` 的默认 100px blur 重置（用 `!important`），否则渐变会被糊成一片。

## 三个踩坑，详见 skill

详见 `~/.workbuddy/skills/stellar-blog-gradient-background/SKILL.md`。

1. convert() 截断含逗号字符串
2. sitebg 100px blur 糊掉渐变
3. **最重要的**：sitebg `<div>` 元素生成条件是 `theme.style.site?.['background-image']` 非空——撤掉配置后即使 inject CSS 写满也没元素可挂（用户第一轮反馈"没看见颜色变化"就是这个原因，已更新到 skill 加 1.5 节）
