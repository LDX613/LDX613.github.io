### 关键发现（容易踩的坑）
- **文档站超前**：xaoxuu.com/wiki/stellar 描述的是尚未发布的下一代配置（site.brand / appearance / topbar|leftbar|rightbar / profiles / extensions.search / stellar doctor / Schema 校验），本地 1.44.0 主题代码不识别，写了等于没写。1.44.0 实际读 `logo` / `menubar` / `site_tree`。
- **theme "welcome" 是死配置**：主题默认 site_tree 里写的 `welcome, recent`，但 `_data/widgets.yml` 没有，模板目录也没有 welcome.ejs，会被静默跳过。
- **`related` 小部件对普通文章无效**：只对 wiki/专栏生效。文章页左栏放它会渲染为空。需要"相关文章"得装 `hexo-related-popular-posts` 插件。
- **分类/标签/归档页 menu_id 硬编码为 `post`**（layout/categories.ejs、tags.ejs、archive.ejs 第 2-4 行）。访问这些页面时"博客"会高亮，无法改成单独高亮。
- **分类/标签/归档页路径**：是 hexo 的 `category_dir` / `tag_dir` / `archive_dir`（默认 `categories`/`tags`/`archives`），**不是**主题默认配置注释里写的 `/blog/categories/`（那行注释是过时的）。
- **博客列表页不存在 `/blog/` 路径**：home 布局在 `/`，index_blog.base_dir 这个配置在 1.44.0 里实际不被生成器使用。
- **分类/标签/归档页只在有数据时生成**：必须文章有 categories / tags，否则不生成。hello-world 没分类时 `/categories/` 是 404。
- **avatar 字段缺失会导致 src="undefined"**：旧格式 `logo.avatar: '[{config.avatar}](/about/)'` 要从站点 _config.yml 读 avatar，否则 undefined。
